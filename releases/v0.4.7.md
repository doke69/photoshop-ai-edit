# Photoshop AI Edit v0.4.7 · 透明圆角图标修正（草稿）

修正 Mac 程序坞、Mac 安装界面、Windows 安装界面与 EXE 图标外侧残留深色方形背景的问题。所有应用图标共用真正带透明通道的圆角 PNG，保留原蓝色主体和内部图案。

- 撤回 v0.4.5 / v0.4.6；公开稳定版暂为 v0.4.4。
- 对最终 Mac ICNS、应用设置给程序坞的图像，以及 Windows Shell 读取的各尺寸图标检查透明边角。
- 收紧 Mac / Windows 双栏比例与步骤间距，统一按钮和页脚；离线指南增加系统首次打开提示的分平台操作。
- DMG 内「请先阅读」同步说明 Mac 的打开流程；EXE 内嵌同一份更新指南。
- 同时提供浅色、深色、棋盘背景对照，供审核边缘、光晕和图案完整性。

本构建保留为草稿，供维护者审核外观。安装前保存文件并完全退出 Photoshop；安装／卸载保留 API Key 与任务历史。
