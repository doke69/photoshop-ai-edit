# Photoshop AI Edit v0.4.4 · Windows 图形安装器

Windows 现在可双击 EXE 安装，沿用 Mac 的深色双栏、品牌 Logo 和三步引导。插件、安装内核与离线 API 教程已包含在 EXE 中，无需先解压或打开命令行。

## 更新内容

- **安装 / 更新、卸载合一**：切换操作，保留 API Key、任务历史及其他插件，旧文件和登记先备份，写入失败时回滚。
- **修复 Windows 兼容问题**：PowerShell 5.1 调用登记替换函数时，将普通空值转换成了非法空路径；现使用真正的 null 字符串。此前可能影响已有登记的升级和卸载。
- **操作反馈**：安装进度、成功后 API 指南入口、失败原因和手动保存诊断记录；安装过程中阻止关闭窗口。
- **一致的设计**：与 Mac 统一品牌与布局，小屏幕缩放完整内容，长错误可滚动，支持键盘焦点。Mac 的深蓝磁盘图标保留。
- **离线指南**：Windows 安装与卸载步骤对应新的 EXE 界面，保留创建 API Key 的截图教程。

## 下载

| 平台 / 方式 | 文件 | 操作 |
| --- | --- | --- |
| Windows 推荐 | `Photoshop-AI-Edit-0.4.4-Windows-Setup.exe` | 双击，选择「安装 / 更新」或「卸载插件」 |
| Windows 命令行备用 | `Photoshop-AI-Edit-0.4.4-Windows.zip` | 完整解压后使用 `Install.cmd` / `Uninstall.cmd` |
| Mac 推荐 | `Photoshop-AI-Edit-0.4.4-macOS-universal.dmg` | 挂载后打开 `Install Photoshop AI Edit.app` |
| Mac ZIP 备用 | `Photoshop-AI-Edit-0.4.4-macOS-universal.zip` | 完整解压后打开安装器 |
| OpenUXP | `photoshop-ai-edit-LK888-0.4.4.ccx` | 使用 OpenUXP 安装 |

操作前保存文件并完全退出 Photoshop。需要 Photoshop 25.0（2024）及以上；Mac 安装器需要 macOS 12 及以上。Windows 图形安装器面向 Windows 10 / 11，使用 .NET Framework 4.8 和系统 Windows PowerShell 5.1，无需 Node.js、Python、开发工具或管理员权限。EXE 尚无代码签名；Mac 尚无 Apple Developer ID 签名 / 公证。

安装包附带离线 HTML 指南，也可单独下载。`SHA256SUMS-v0.4.4.txt` 提供安装文件校验值。Windows 听写与标注等本机辅助服务仍需另行启动，未捆绑到安装器。

## 验证范围

Windows Server 2022 云端运行了隔离目录测试：中文路径、带 BOM 的登记、首次安装、升级备份、未知登记字段和其他插件保留、私有数据保留、安装及卸载异常回滚、重复卸载、损坏登记和目标占用保护。最终 EXE 通过 Windows UI Automation 实际点击安装和卸载，逐个对比内嵌插件文件哈希；预览模式生成界面截图且不访问 Adobe 目录。

以上不等于 Windows 10 / 11 用户电脑和 Photoshop 实机加载验证，仍需用户审核；未调用付费生图 API。此前用户确认的 OpenUXP 安装验证对应 v0.4.2。
