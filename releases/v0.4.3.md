# Photoshop AI Edit v0.4.3 · 安装、卸载与 API 上手指南

新增 Mac DMG 安装包与 Windows 便携安装入口，安装、卸载和首次 API 配置都有操作引导。挂载磁盘采用新设计的深蓝色品牌图标，安装应用使用独立方形 Logo。

## 本次更新

- **Mac 安装与卸载界面**：支持 Apple Silicon / Intel，深色双栏设计，提供「安装 / 更新」和「卸载插件」。无需管理员权限、Node.js 或 UXP 开发工具。
- **保留本机数据**：安装前备份旧插件文件和登记；卸载保留 API Key、任务历史及其他插件。异常写入时尝试回滚。
- **首次 API 配置**：没有保存 Key 时自动进入设置页，按「获取 Key → 保存 → 检查连接与同步模型 → 返回改图」显示进度。检查连接不提交付费生图。
- **截图教程**：离线 HTML 内含主站入口、API 开放平台、控制台导航、创建表单及「价格优先」「无限制」设置的真实截图标注；截图排除账号 ID、余额和密钥内容。
- **布局修复**：任务核对改用独立确认行，长文字自然换行；恢复结果与结束任务按钮分行布局，修复原生复选框说明与按钮重叠。
- **品牌图标**：方形应用图标采用铺满画布的设计；DMG 挂载磁盘使用深蓝色统一材质，Logo 图形直接位于磁盘正面。

## 下载与安装

| 平台 / 方式 | Assets 文件 | 操作 |
| --- | --- | --- |
| Mac 推荐 | `Photoshop-AI-Edit-0.4.3-macOS-universal.dmg` | 双击挂载，打开其中的 `Install Photoshop AI Edit.app` |
| Mac ZIP 备用 | `Photoshop-AI-Edit-0.4.3-macOS-universal.zip` | 完整解压后打开安装器 |
| Windows | `Photoshop-AI-Edit-0.4.3-Windows.zip` | 完整解压，双击 `Install.cmd`；卸载使用 `Uninstall.cmd` |
| OpenUXP / Creative Cloud | `photoshop-ai-edit-LK888-0.4.3.ccx` | 使用 [OpenUXP](https://moonvy.com/apps/upx-installer/) 打开，也可尝试 Creative Cloud |

操作前保存文件并完全退出 Photoshop。需要 **Photoshop 25.0（2024）及以上**；Mac 安装器需要 macOS 12 及以上。安装器直接安装插件，无需拖入 Applications。启动 PS 后，在「增效工具 → AI 局部改图」中打开。

安装包内附「安装与使用指南.html」，本页也提供单独的 HTML 下载。GitHub 自动生成的 Source code 压缩包是源码，不是直接安装包。`SHA256SUMS-v0.4.3.txt` 提供四种安装包的校验值。

## 创建 API Key

通过 [LK888 注册入口](https://ac.lk888.ai/zh-CN?yonghu=UBOJB2UXX2V5ZFCU) 注册 / 登录，进入「API 开放平台 → 控制台 → API 密钥」，创建时选择「价格优先」。示例选择无限制，会直接按账户余额扣费；也可自行设置算力限额。Key 仅完整显示一次，请自行安全保存，再粘贴到插件设置中保存并检查连接。

新用户注册赠 **1 元体验额度**；GPT2.5「价格优先」单次改图参考价低至 **人民币 ¥0.025 / 张**。活动与价格信息由项目维护者提供（2026-10-18），具体条件、渠道、规格、到账和实际计费以平台为准。安装包不包含任何用户 Key。

## 验证与兼容说明

- **132 项自动测试通过**；安装 / 卸载在隔离临时目录验证首次安装、升级、其他插件与私有数据保留、备份、异常回滚和重复卸载。测试未调用付费生图。
- Mac 安装应用为本地临时签名，**没有 Apple Developer ID 签名或公证**，系统可能阻止首次打开。可改用 CCX + OpenUXP。此前 v0.4.2 的 OpenUXP 安装已由用户实机验证；本次新安装器的真实 Photoshop 加载和 Windows 安装脚本仍待实机验证。
- Windows 语音、标注与部分剪贴板辅助功能需另外启动源码中的本机助手；本安装器不捆绑辅助服务。Mac 使用系统听写。
- 桌面仍显示旧磁盘图标时，先推出旧映像，再打开新版 DMG。
