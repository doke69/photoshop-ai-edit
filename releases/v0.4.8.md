# Photoshop AI Edit v0.4.8 · 提交状态与本地存储加固

修复面板重载或崩溃后可能重复提交，以及本地存储配额异常导致已受理 Task ID 丢失的问题。

## 修复

- 提交前先持久化 `pendingSubmit`；无法写入本机时取消提交，避免平台已受理但本地没有记录。
- 启动时对账中断的 `submitting` / `pendingSubmit` 记录：任务编号不完整统一转为「待确认」，阻止再次生成；任务编号完整则恢复原状态。
- 「提交中」与「待确认」一样阻止再次生成，需先在平台核对，再结束待确认记录。
- 本地存储失败不再抛出并中断界面；配额不足时优先保留任务 ID，缩略图可退化或省略保存。
- Task ID 落盘失败时停止继续提交剩余图片，已提交任务仍会继续查询；重载后转「待确认」，避免重复扣费。
- 新增 8 项插件回归测试，共 140 项自动测试通过；另补充安装器指南文件检查。

- 修复 Mac 指南打开路径：保存独立 HTML 后明确交给浏览器打开，并显示失败原因与 Finder 定位入口。
- Windows 指南保存到用户本地目录，退出安装器后不再丢失；卸载完成按钮改为关闭窗口。
- 任务编号保存失败但仍在查询时，持续阻止再次生成，直到用户明确核对。
