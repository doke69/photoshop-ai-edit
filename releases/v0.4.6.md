# Photoshop AI Edit v0.4.6

Windows 安装器更换为新的品牌 Logo，并改善安装窗口的清晰度。

- EXE 文件图标、安装窗口 Logo 与任务栏图标使用同一张高清原图。
- 优化图片缩放，支持高分屏和不同显示器的 DPI 切换。
- 安装／更新和卸载均保留 API Key 与任务历史，安装后可打开 API 设置指南。

## 下载安装

| 系统 / 方式 | 下载文件 | 使用方法 |
| --- | --- | --- |
| Windows 推荐 | `Photoshop-AI-Edit-0.4.6-Windows-Setup.exe` | 双击安装器，选择安装／更新或卸载 |
| Mac 推荐 | `Photoshop-AI-Edit-0.4.6-macOS-universal.dmg` | 打开磁盘映像，再双击其中的安装器 |
| OpenUXP | `photoshop-ai-edit-LK888-0.4.6.ccx` | 用 OpenUXP 打开并安装 |

安装前保存文件并退出 Photoshop。需要 Photoshop 2024 / 25.0 及以上；Mac 安装器需要 macOS 12 及以上，Windows 安装器需要 .NET Framework 4.8 和系统 PowerShell 5.1。安装器无需管理员权限。

Assets 另附 Mac / Windows ZIP 备用包、离线指南、ICO 图标与 SHA256 校验文件。EXE 已自带图标，ICO 仅用于手动设置快捷方式。

安装器尚无开发者签名／公证，系统可能提示发布者未知。真实 Photoshop 加载仍需按你的电脑环境确认。
