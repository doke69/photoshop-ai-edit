# Windows installer icon

`windows-installer.png` is the exact 1254 × 1254 PNG selected and supplied by the user on 2026-10-18. It is copied without image edits or resampling. This asset is used for the Windows EXE icon and the WPF window branding. The Mac icon and mounted-disk design have their own existing assets.

The EXE contains 16–256 px ICO frames generated from this master. The WPF image uses the full original PNG, high-quality bitmap scaling, device-pixel snapping, and Per-Monitor V2 DPI awareness. The .NET target is explicitly 4.8. Build previews support 1x and 2x output; they do not install the plugin.
