01 /

先把插件装进 Photoshop

操作前保存文件并完全退出 Photoshop，安装后重新启动。

macOS · APPLE SILICON / INTEL

打开 DMG，双击安装器

打开 .dmg，双击其中的 Install Photoshop AI Edit.app，选择「安装 / 更新」。ZIP 版先完整解压，再打开安装器。

这是 Photoshop 插件安装器，无需拖入 Applications。

WINDOWS

双击 EXE，按向导安装

下载 Windows 图形安装器 Windows-Setup.exe，双击打开，选择「安装 / 更新」。界面与 Mac 一致，插件和离线指南已包含，无需解压。

安装无需管理员权限、Node.js 或 UXP 开发工具。

备用安装方式：将同版本 CCX 拖入 OpenUXP。Mac 安装器未取得 Apple 开发者签名 / 公证，若系统阻止打开可使用此方式。Windows 10 / 11 实机与本次安装器的真实 PS 加载仍待验证；此前 v0.4.2 已由用户完成 OpenUXP 安装验证。

注册账号，创建「价格优先」API Key

主站账号注册后，进入「API 开放平台」创建密钥，再把 Key 保存到插件。

新人体验
新用户注册赠 1 元体验额度

可用于体验平台服务；活动条件、额度用途与到账情况以平台实时规则为准。本项活动信息由项目维护者提供。

  1. 通过注册入口创建账号并登录

    打开下方链接，按页面提示完成注册 / 登录、验证码和协议确认。已有账号直接登录，无需重复注册。

    打开 LK888 注册入口 ↗

  2. 进入 API 开放平台 → 控制台 → API 密钥

    在主站导航或页脚找到「API 开放平台」，进入后点击「进入控制台」，再在侧栏选择「API 密钥」。窗口较窄时先展开左上角导航。

  3. 创建密钥，渠道策略选择「价格优先」

    点击「创建 API 密钥」，按下方实机表单填写。这里设置的是密钥的渠道策略，不是在插件中选择模型。

    1

    名称

    例如「Photoshop AI Edit」，便于识别这把 Key 的用途。

    2

    渠道策略：价格优先

    平台会使用该模型当前最便宜的渠道。模型可用性与具体价格以平台为准。

    3

    额度：无限制

    本示例不设密钥累计上限，直接按账户余额扣费；也可按自己的预算设置限额，限额单位为平台「算力」。

    4

    确认后创建

    IP 白名单按需设置；仅用于插件调用时，可保持「允许通过接口修改配置」关闭，再点击「创建 API 密钥」。

  4. 复制并安全保存 Key，再回到插件

    平台会提示「密钥仅此一次完整显示」，请立即自行复制保存，然后再关闭提示。不要把 Key 放进公开截图、聊天、GitHub 或 HTML 教程。

    启动 Photoshop →「增效工具」→「AI 局部改图」→「设置」，粘贴 Key 并点击「保存密钥」，再点击「检查连接」。鉴权成功后自动同步模型，最后返回改图。

03 /

圈出区域，告诉 AI 怎么改

  1. 在 Photoshop 中框选或套索选区

    打开 RGB 文档，选中要修改的位置。回到插件点击「读取选区」，缩略图会显示当前上传区域。

  2. 填写要求，按需添加参考图

    说明要改的内容；参考图可用于风格、人物或物品参考。不要把参考图当成新的选区。

    提示词示例把西装换成浅蓝色，保留人物姿态、背景与光线。

  3. 选择模型和规格

    选择已同步的图像模型，按模型支持的范围设置清晰度、张数和比例。选区会先尝试 PNG 无损压缩，超过上传预算时等比缩小。

04 /

生成候选图，回填独立图层

  1. 点击「生成当前选区」

    生成会使用平台额度；多张会创建多个任务。等待期间保留原文档，避免改变画布尺寸。

  2. 查看结果，添加为图层

    完成后选择候选结果，按原坐标添加为独立图层；也可放大预览、下载原图或再次添加。

  3. 继续修改其他区域

    点击「新建」读取新选区。原任务保留在标签与历史中，方便恢复输入和结果。

HELP /

维护与常见问题

如何卸载？会删除 Key 和历史吗？

Mac：重新打开 DMG 内的安装器，切换「卸载插件」，点击「卸载插件（保留数据）」。Windows：重新打开 Windows-Setup.exe，切换「卸载插件」。旧 ZIP 包也可使用 Uninstall.cmd。操作前保存文件并退出 Photoshop，下次启动生效。

卸载只移除本插件文件与登记，保留 API Key、任务历史及其他插件。旧插件文件与登记备份至 Adobe UXP 用户目录的 Plugins/.AIEditInstallerBackups。

插件没有出现，或安装器无法打开

确认 Photoshop 为 25.0 或更新版本，并完全退出后重新启动。若 Mac 系统阻止未公证的安装器，使用同版本 CCX 与 OpenUXP。安装器未捆绑用户密钥。

连接失败或同步不到模型

核对 Key、平台账号和网络。同步失败会保留内置预设及缓存，可手动重试。模型能力和报价由平台提供，不同账号可用模型可能不同。

任务显示「待确认」，能直接重新生成吗？

先到平台核对原任务，避免重复付费。核对后再勾选设置页中的确认项，结束本机记录；这不会取消平台任务。

听写、标注等辅助功能如何启用？

Mac 使用系统设置中的中文听写。Windows 语音、标注及部分剪贴板功能需另外启动源码中的本机助手；安装器不捆绑该服务，详见项目 README。
